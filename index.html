Development roadmap

Planned stages of work, Subject to change.

Phase 1

Core systems

Implement player sync, voice chat, and more basic systems.

Phase 2

Launcher

Create a very basic launcher that deploys client mods and allows connection to the server.

Phase 3

Skills and interface

Add civilian and criminal skill trees.
Redo user interfaces to match our project's theme.

Phase 4

Jobs and guards

Add job menus for hiring.
Implement guardsman systems for arrest and imprisonment.

Phase 5

Alpha

Refine the launcher.
Add automatic updates.
Implement accounts with whitelist.
Release the first alpha test.

Ongoing

SkyMP and hosting

Work on understanding SkyMP and obtaining a test server for development.
